description=Documents a QGIS project for people and machines: Markdown, HTML, PDF and rebuild-grade JSON.
about=DocQGISProject writes a complete description of a QGIS project: layers and data sources (credentials redacted), styling, print layouts and every layout item, project settings, metadata and quality checks. People get readable Markdown, HTML and PDF reports with rendered images; machines get a schema-versioned JSON file complete enough to rebuild the project. The plugin is read only: it never modifies the project or its data and never runs project macros. Development build: JSON, Markdown, HTML and PDF output from the Python console; the dialog, the Processing algorithm and the project rebuilder are still in progress.
